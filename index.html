System Overview

About SCRTMS (Campus Diary)

Built according to official Software Requirements Specifications to address institution challenges by replacing manual paper tracking and scattered spreadsheets with an integrated client-side system.

Student Module

Students receive a personalized workspace to view assigned coursework tasks with color-coded priority badges, track submission deadlines, read official campus notices, and monitor lab bookings.

Teacher Module

Teachers are equipped with tools to create and assign tasks to specific enrolled students, track task completion percentages, upload course study notes, and publish class announcements.

Admin Module

Administrators possess full platform supervision, user account management (CRUD operations), real-time activity audit logging, resource conflict prevention, and Chart.js analytics.

Core Features

Powerful Campus Capabilities

Everything needed to manage academic tasks, facilities, announcements, and administrative audit trails.

Task Management

Assign coursework, track status (Pending, In Progress, Completed), set priority tags (High, Medium, Low), and enforce deadlines.

Conflict-Free Booking

Book Classrooms, Computer Labs, Science Labs, and Seminar Halls. Automated conflict algorithm prevents double-booking time slots.

Notice Board

Publish official announcements categorized by Exams, Events, Maintenance, and General. Pin urgent notices to the top of the feed.

Analytics & Audit Logs

Chart.js visualizations for task completion rates and user distribution, accompanied by real-time administrative activity audit trails.
