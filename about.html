SRS Specifications

Smart Campus Resource & Task Management System

A centralized web platform replacing manual tracking across paper notes, Excel sheets, and messaging groups.

Student Workspace

Track course assignments with color-coded deadline indicators, monitor task completion statuses, read announcements, and access resources.

Teacher Portal

Assign tasks directly to students, track individual completion rates, upload lecture study materials, and publish official class announcements.

Admin Supervision

Manage system user accounts, audit real-time activity logs, enforce resource conflict-prevention algorithms, and view analytics charts.

System Modules & Functional Breakdown

Module 1: Landing & Authentication

Handles role-based authentication (Student, Teacher, Admin), user registration, password recovery, client-side input validation, and LocalStorage state persistence.

Module 2 & 3: Task & Coursework Management

Enables teachers to assign coursework tasks with priorities (High, Medium, Low) and deadlines. Allows students to update status from Pending to In Progress and Completed.

Module 4: Resource Booking & Collision Prevention

Tracks availability for Classrooms, Computer Labs, Science Labs, and Seminar Halls. Features an automated collision-prevention algorithm to prevent double-booking the same room and time slot.

Module 5: Admin Panel & Activity Audit Logs

Provides full control over user accounts, detailed audit logs capturing every user action, and Chart.js analytics reports showing user distribution and resource usage.
